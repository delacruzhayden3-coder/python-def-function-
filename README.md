# Temperature Converter

This is a simple Python program that converts a temperature from Celsius to Fahrenheit.

## How It Works

The program uses a `def` function called `celsius_to_fahrenheit()` to perform the conversion.

The formula used is:

Fahrenheit = (Celsius × 9/5) + 32

## How to Run

1. Open the Python file.
2. Run the program.
3. Enter a temperature in Celsius.
4. The program will display the equivalent temperature in Fahrenheit.

## Example

Enter temperature in Celsius: 25

Temperature in Fahrenheit: 77.0
