Temperature Converter

Description

This is a simple Python program that converts a temperature from Celsius to Fahrenheit.

The program uses a "def" function called "celsius_to_fahrenheit()" to perform the temperature conversion.

How It Works

1. The user enters a temperature in Celsius.
2. The program calls the "celsius_to_fahrenheit()" function.
3. The function converts the temperature to Fahrenheit.
4. The converted temperature is displayed on the screen.

Formula

Fahrenheit = (Celsius × 9/5) + 32

Example

Enter temperature in Celsius: 25
Temperature in Fahrenheit: 77.0

Files

- "README.md" – Contains information about the project.
- "temperature_converter.py" – Contains the Python program.

Purpose of the def Function

The "def" function is used to create a reusable block of code that performs the Celsius-to-Fahrenheit conversion.
