Python Def Function Activity

Description

This project demonstrates how to use a "def" function in Python.

The program asks the user to enter three grades and then calculates the average of the three grades.

How the Program Works

1. The program asks the user to enter the first grade.
2. The program asks the user to enter the second grade.
3. The program asks the user to enter the third grade.
4. The "calculate_average()" function calculates the average of the three grades.
5. The function is called/invoked by the program.
6. The calculated average is displayed on the screen.

File

- "def_activity.py" – Python program that demonstrates the use of a "def" function.

Purpose

The purpose of this activity is to demonstrate how a "def" function can be created and called in a Python program.
